# 🎬 Netflix Movies EDA: 1990s Decade Analysis

An Exploratory Data Analysis (EDA) of Netflix movies released during the 1990s decade (1990–1999). This project uses Python and Pandas to analyze trends in movie durations and identify specific sub-genres, such as short action films.

---

## 📌 Project Overview

The objective of this analysis is to answer key historical questions about movie releases on Netflix during the 1990s:
1. **Most Frequent Duration:** What was the most common movie length (mode) during the 1990s?
2. **Short Action Movies:** How many short action films (duration under 90 minutes) were released in this decade?

---

## 📊 Key Findings

* **Most Frequent Movie Duration:** `94` minutes
* **Short Action Movies Count:** `7` movies
